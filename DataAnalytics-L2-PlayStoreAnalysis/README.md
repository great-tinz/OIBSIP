# Task 3: Google Play Store Analysis

This was my final and largest task for the internship. I analyzed two datasets from the Google Play Store to figure out what makes an app successful.

I started by cleaning the install numbers and prices so I could actually do math on them. Then I generated charts to see which categories were the most crowded and what the average ratings looked like. 

The coolest part was merging the main app data with a user reviews dataset. This let me do a sentiment analysis to see which app categories got the most positive and negative feedback from users.
