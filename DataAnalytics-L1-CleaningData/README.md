# Task 2: Data Cleaning

This was one of the most practical tasks. I downloaded a deliberately messy HR dataset to practice my data wrangling skills.

I had to handle missing values, drop duplicates, and standardize really weird text formats. For example, some salaries were written as words instead of numbers, and dates were all over the place. 

I used median imputation to fill in missing numbers without skewing the data, and I plotted some boxplots using the IQR method to check for outliers. You can find both the messy dataset and my final cleaned CSV in the data folder.
