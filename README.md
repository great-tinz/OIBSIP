# Oasis Infobyte Data Analytics Internship Tasks

This repository contains my completed projects for the Oasis Infobyte self-paced Data Analytics internship. I have successfully completed all three assigned tasks and organized them into their respective folders.

For the first task, I performed an Exploratory Data Analysis on a retail sales dataset. I focused on understanding customer demographics and purchasing habits. I analyzed how different age groups and genders interacted with various product categories, and I visualized the sales trends over time to see which months generated the most revenue.

For the second task, I took on the challenge of data cleaning using a messy HR dataset. I systematically handled missing values by using median imputation for numerical data and placeholder text for missing contact information, ensuring no rows were unnecessarily deleted. I also standardized text formatting and converted dates into proper datetime formats to prepare the dataset for analysis.

For the final task, I conducted a comprehensive analysis of the Google Play Store ecosystem. I cleaned install numbers and pricing data to explore market saturation and pricing strategies across different app categories. I then merged the main dataset with a user reviews dataset to perform a sentiment analysis, identifying which specific app categories received the most positive and negative feedback from users.

All Jupyter Notebooks containing my code, visualizations, and conclusions are included in the folders for review.
