# Task 1: Retail Sales EDA

For my first project, I did an exploratory data analysis on a retail sales dataset. 

I loaded the data and generated a few charts to understand the purchasing behavior of the customers. I binned the customer ages into specific groups, checked out the gender distribution, and plotted a line chart to see how sales trended over different months. 

It was a great way to get comfortable with pandas grouping and basic data visualization using seaborn.
